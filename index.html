รายชื่อนักเรียน

ลำดับเลขบัตรประชาชนชื่อ - นามสกุลชั้นห้องเพศอายุ

ตั้งค่าการเชื่อมต่อ Google Sheets

วางลิงก์ Web App ที่ได้จาก Google Apps Script เพื่อเชื่อมหน้าเว็บกับฐานข้อมูล

  1. เปิด Google Sheet → เมนู ส่วนขยาย → Apps Script
  2. วางโค้ดจากไฟล์ Code.gs แล้วบันทึก
  3. กด ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ → เว็บแอป
  4. ตั้งสิทธิ์เป็น ทุกคน (Anyone) แล้วคัดลอกลิงก์ Web App มาวางด้านล่าง
ลิงก์จะถูกจดจำไว้ในเครื่องนี้ ไม่ต้องวางใหม่ทุกครั้ง
